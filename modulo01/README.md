# 🍧 Sistema de Vendas - Açaiteria

## Funcionalidades Principais

O sistema foi desenvolvido para auxiliar no gerenciamento de produtos e vendas de uma açaiteria, proporcionando uma forma simples de cadastrar produtos, controlar informações e realizar vendas.

### Funcionalidades disponíveis:

* Cadastro de novos produtos.
* Listagem de produtos cadastrados.
* Realização de vendas.
* Listagem de vendas.
* Análise de dados de vendas.
* Criação de uma interface de usuário.
* Implementação de funcionalidades para o sistema.
* Otimização de estratégias de marketing.
* Cadastro de clientes.
* Controle de informações dos produtos, como código, nome, marca, quantidade, preço, validade e lote.

## 📦 Cadastro de Produtos

O sistema permite cadastrar informações importantes dos produtos da açaiteria, como:

* Código do produto.
* Nome do produto.
* Marca.
* Quantidade em estoque.
* Estoque mínimo.
* Preço de custo.
* Validade.
* Lote.
* Descrição.

---

## 💰 Realização de Vendas

A opção de realização de vendas permite registrar informações relacionadas à venda, incluindo:

* Código da venda.
* Nome do cliente.

Essa funcionalidade serve como base para o controle das vendas realizadas pela açaiteria.

## 📊 Sistema de Menus

O programa possui um menu principal com as seguintes opções:

```text
1 - Cadastrar produto
2 - Listar produtos
3 - Realizar venda
4 - Listar vendas
5 - Analisar dados de vendas
6 - Criar interface de usuário
7 - Implementar funcionalidades
8 - Otimizar estratégias de marketing
9 - Cadastrar cliente
0 - Sair
```

---

## 🔄 Funcionamento

Ao iniciar o programa, o usuário recebe uma mensagem de boas-vindas e pode escolher uma das opções disponíveis no menu.

O sistema utiliza uma estrutura de repetição para manter o menu disponível enquanto o programa estiver sendo executado. Cada opção direciona o usuário para uma funcionalidade específica.

Caso seja escolhida uma opção inexistente, o sistema informa:

```text
Opção inválida. Por favor, selecione uma opção válida.
```
